# Personal Journal Manager

A simple Python project to manage daily journal entries.

## Features

1.Add new journal entries with date and time.

2.View all saved entries.

3.Search entries using keywords.

4.Delete all journal entries.

5.Simple menu-based program.

## Concepts Used

1.Python Classes and Objects

2.Functions and Methods

3.Loops and Conditional Statements

4.File Handling

5.Exception Handling

6.DateTime Module
